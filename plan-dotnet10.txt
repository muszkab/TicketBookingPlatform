status/category paraméter string helyett típusos enum (EventCategory/EventStatus/TicketStatus).

FÁZIS 7 - StringEnumSchemaTransformer kiváltása (opcionális; függ: 3)
-------------------------------------------------------------------
Háttér: az OpenAPI generátor a Microsoft.AspNetCore.Http.Json.JsonOptions beállításait használja, nem az MVC-s
JsonOptions-t. A JsonStringEnumConverter jelenleg csak az MVC-nél van regisztrálva, ezért kell a transformer.
25. src/WebApi/Program.cs: a már meglévő ConfigureHttpJsonOptions hívásba (3. fázis, NumberHandling = Strict)
    bele: o.SerializerOptions.Converters.Add(new JsonStringEnumConverter());
26. A transformer regisztrációjának törlése (src/WebApi/Infrastructure/ApiDocumentationExtensions.cs),
    az osztály (StringEnumSchemaTransformer.cs) és a tesztjei (StringEnumSchemaTransformerTests.cs) törlése.
27. npm run refresh:api -> v1.json diff a 3. fázis eredményéhez képest: az enum sémák változatlanok
    (type string + enum nevek); nullable enum tulajdonságok helyes 3.1-es leírása.
28. dotnet test + npm test + npm run build zöld.
Előny: ~1 osztály + ~10 teszt kevesebb, nullable enumokat a keretrendszer kezeli.
Hátrány: a converter két helyen regisztrált (MVC + Http), szinkronban kell tartani.
